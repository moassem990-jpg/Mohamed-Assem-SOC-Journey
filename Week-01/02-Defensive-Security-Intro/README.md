1. Introduction

Defensive Security focuses on protecting an organization's systems, networks, and data by detecting threats, investigating suspicious activities, and responding to security incidents.

2. Key Security Concepts

SOC

A Security Operations Center monitors organizational systems and responds to security incidents.

Baseline

A baseline represents the normal behavior of a system or user. Deviations from this baseline may indicate suspicious activity and require investigation.

Brute Force Attack

A brute force attack involves repeated attempts to guess a user's password.

Containment

Containment is an immediate action taken to limit an attack and reduce its impact, such as locking a targeted account.

Threat Intelligence

Threat intelligence involves collecting and updating information about threat actors, their behaviors, and their targets.

Incident Report

An incident report documents what happened, the investigation findings, and the actions taken.
